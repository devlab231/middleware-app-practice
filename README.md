# middleware-app-practice

## 概要
COACHTECH 教材 Tutorial 10-2「ミドルウェア ハンズオン演習」で作成した成果物です。<br>
Laravelのカスタムミドルウェアを使用して、管理者と一般ユーザーのアクセス権限を制御するWebアプリケーションを作成しました。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- カスタムミドルウェア
- Laravel Fortify（認証）

## 学んだこと
- ミドルウェアの仕組み
- カスタムミドルウェアによるアクセス制御
- ミドルウェアの登録と適用

## 動作確認
GitHubから本プロジェクトを取得し、Laravel Sailを使用して起動することで動作確認できます。<br>
管理者ユーザーでログインすると管理画面にアクセスでき、一般ユーザーでログインすると「管理者権限が必要です」と表示され、403エラーが返されることを確認してください。<br>
※ 実行にはDocker環境および初期設定が必要です。
